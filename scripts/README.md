# scripts

Ppipeline for the whole process:

- Basecalling wrappers for Dorado (for DeepRM no).
- Splice-aware alignment wrappers for Minimap2.
- BAM quality-control summaries.
- Tool-specific preprocessing and output collection for DeepRM, m6Anet, Dorado
  modification calling using Modkit, and SingleMod.
- Groung truth: GLORI preparation for HEK293T and eTAM-seq preparation for HeLa.
- Standardization.
- Benchmarking.
- Visualization.
