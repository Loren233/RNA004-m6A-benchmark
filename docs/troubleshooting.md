# Troubleshooting

This document collects troubleshooting notes for local or HPC reruns of the
current workflow wrappers and analysis scripts.

- Missing local path configuration.
- Reference genome or annotation mismatches.
- Coordinate-system and strand-convention mismatches.
- BAM indexing or alignment quality-control issues.
- Tool-specific input and output format differences.
- Empty matched-site tables after coordinate-offset matching.
