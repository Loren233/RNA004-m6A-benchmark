# environments

Reproducible software environment definitions will live here.

Planned environment records may include Conda or Mamba YAML files, Apptainer or
Docker notes, and HPC module documentation for:

- Dorado
- Minimap2
- Samtools
- DeepRM
- m6Anet
- SingleMod
- Python and R analysis dependencies

Do not record software versions until they are verified. When versions are
known, mirror them in `metadata/software_versions.tsv`.
